\# Supply Chain \& Inventory Analysis



\## 📌 Project Overview



This project analyzes supply chain and inventory data to understand

order fulfillment, inventory levels, supplier performance, delivery

performance, pending quantities, and order value trends.



The project follows an end-to-end data analytics workflow using

Excel, SQL Server, and Power BI.



\---



\## 📊 Dataset Overview



\- Total Orders: 550

\- Suppliers: 9

\- Products: 30

\- Warehouses: 5

\- Order Date Range: 01-Jan-2025 to 24-Feb-2026



\---



\## 💰 Key KPIs



\- Total Order Value: 465.43M

\- Total Pending Quantity: \~30K

\- Total Stock Level: \~87K

\- Total Orders: 550



\---



\## 🔎 Key Business Insight



\- 68.2% of orders were delivered successfully.

\- 18.0% of orders were partially delivered.

\- 13.8% of orders were either cancelled or still in transit.



These results highlight opportunities to improve order fulfillment,

inventory planning, and supplier delivery performance.
